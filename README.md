# Tasbih Pro 🕌

A beautiful, feature-rich dhikr counter web app for Muslims.

## Features

- **Custom Tasbihs** - Add, edit, or delete your own zikir
- **Goal Tracking** - Set and track your daily dhikr goal
- **Statistics** - View today's count, streak, weekly chart, and all-time total
- **Multi-platform** - Works on desktop and mobile
- **Offline** - Saves data locally, works without internet

## How to Use

### Mobile
- **Tap** the counter to increment
- **Tap "− decrease"** button to decrement

### Desktop
- **Enter** - Increment
- **Backspace** - Decrement
- **Up Arrow** - Undo last count

## Getting Started

1. Open `index.html` in your browser
2. Add your own tasbihs in Settings (gear icon)
3. Set your daily goal by tapping the ✏️ icon
4. Start counting!

## Tech

- Pure HTML/CSS/JS - no dependencies
- LocalStorage for data persistence
- Web Audio API for sound
- Mobile-first responsive design
