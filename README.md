## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧮 **Smart Counter** | Tap to count, tap to decrease - no confusing gestures |
| 🎯 **Goal Tracking** | Set your daily dhikr goal and track progress |
| 📊 **Statistics** | Today's count, streak, weekly chart, all-time total |
| ✏️ **Custom Tasbihs** | Add, edit, or delete your own zikir anytime |
| 🔔 **Sound & Haptic** | Optional sound and vibration feedback |
| 💾 **Offline** | Works without internet, saves locally |
| 📱 **Mobile First** | Beautiful on any screen size |

## 🚀 Quick Start

```bash
# Just open in browser - no installation needed!
open index.html
```

Or simply drag `index.html` into your browser.

---

## ⌨️ Keyboard Shortcuts (Desktop)

| Key | Action |
|-----|--------|
| <kbd>Enter</kbd> | Increment |
| <kbd>Backspace</kbd> | Decrement |
| <kbd>↑</kbd> | Undo last count |

---

## 📱 Mobile Usage

- **Tap** the big circle to increment (+1)
- **Tap** the "− decrease" button to decrement (-1)
- **Swipe up** to undo last count

---

## 🔧 Customization

1. Click the **⚙️ Settings** icon to open settings
2. Add your own tasbihs in the "Custom Tasbih" section
3. Tap the **✏️** icon next to "Daily Goal" to set your target

## 🛠️ Tech Stack

- Pure **HTML5, CSS3, JavaScript** - zero dependencies
- **LocalStorage** for data persistence
